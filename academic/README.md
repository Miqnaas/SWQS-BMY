# Academic research deliverables

The project includes a completed Sections 1–4 research paper (PDF & DOCX) and a unified EDA / preprocessing notebook.

- EDA/preprocessing notebook is available at \`notebooks/Water_Quality_EDA_Preprocessing.ipynb\`.
- Model training notebook is at \`notebooks/Model_Training_Evaluation.ipynb\`.
- The academic PDF and DOCX are prepared locally, but binary export files have not yet been added to this public GitHub repository.

For provenance, see the university project's original proposal and team deliverables. ML training and the interactive lab are subsequent extensions, not claims made in the original Sections 1–4 paper.
