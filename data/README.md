# Dataset

The original `water_potability.csv` was used for university research, but this public repository intentionally does not redistribute the raw Kaggle file until the publisher's redistribution terms have been verified.

Download from: https://www.kaggle.com/datasets/adityakadiwal/water-potability

Place it at `data/water_potability.csv` and run `python -m ml.train`.

Expected columns, in order:
`ph, Hardness, Solids, Chloramines, Sulfate, Conductivity, Organic_carbon, Trihalomethanes, Turbidity, Potability`.

This source contains 3,276 labeled observations. The labels are not independent drinking-water safety certifications.
